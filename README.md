# Pont des Morts

Jeu de tir zombie en 3D (Three.js), jouable dans le navigateur, sur téléphone comme sur ordinateur.

- Glisse le doigt (ou flèches / A-D) pour déplacer l'escouade à gauche ou à droite.
- Passe dans les portes bleues (+N, ×2) et évite les rouges (−N, ÷2). Tire sur une porte pour faire monter son chiffre.
- Détruis les bidons violets pour améliorer ton arme, les verts pour recevoir des renforts.
- Abats le Mastodonte à la fin de chaque niveau.

Tout le jeu tient dans `index.html`. Pour y jouer : ouvre le fichier dans un navigateur, ou active GitHub Pages (Settings → Pages → branche, dossier racine).
